# MANJOS Livestock & Farms

A responsive React website for MANJOS Livestock & Farms in Obudu, Cross River State, Nigeria. Built with React and Vite.

## Run locally

```sh
npm run dev
```

Open the local URL printed by Vite in your browser. To create and locally serve a production build, run `npm run build` and then `npm run preview`.

## Before publishing

- Replace the clearly labelled example animal cards in `src/App.jsx` with confirmed inventory, photos, age or size, prices, and availability.
- Confirm the farm WhatsApp number and add an email address. The WhatsApp button opens a direct chat at the provided number.
- Confirm the farm's precise visit location and directions before publishing them.
- The map link currently points to the general Obudu Mountain Resort area, not a verified farm pin.

The website does not process payments or verify animal health, availability, or sale details. Buyers should confirm details with the seller and arrange an in-person inspection before purchase.
